# Changelog

## 1.0.0

Initial release for the Gather v1 desktop app on macOS. Gather v2 beta is not supported.

- Set Gather's game speed to 4× from Raycast.
- Save named locations and teleport to them from a searchable list. Saved spots include the Gather space, map, and coordinates and can be removed when no longer needed.
- Copy a saved spot as an entry for the standalone teleport script.
- Use standalone Raycast script commands to set 4× speed, copy the current location, and teleport to configured favorite spots.
